# SignSpeak — Sign Language Recognition

## Overview

SignSpeak is a sign language recognition project
designed to recognize hand gestures using computer
vision and a CNN-based deep learning model.

## Technologies Used

- Python
- OpenCV
- TensorFlow / Keras
- Convolutional Neural Networks (CNN)
- HTML
- CSS

## Project Structure

- Files: Python source files
- frontend2: Frontend and interface files
- Model: Trained CNN model
- reports: Project reports and documentation

## Features

- Hand gesture recognition
- CNN-based image classification
- Sign language recognition interface
- Supporting Python scripts

## Model

The trained CNN model is stored in the Model folder.

## Dataset

The dataset is not included in this repository.
Refer to the project documentation for dataset details
and availability.

## Installation

Install the required Python dependencies before
running the application.

## Project Status

This repository contains the project's source files
and trained model. Setup and execution may require
additional configuration.
